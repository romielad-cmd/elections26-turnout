# קפיצות בשיעור ההצבעה – בחירות לכנסת ה־26

ניתוח שיעור ההצבעה בכל קלפי בבחירות 27 באוקטובר 2026, בהשוואה לממוצע של חמש מערכות הבחירות הקודמות
(אפריל 2019, ספטמבר 2019, מרץ 2020, מרץ 2021, נובמבר 2022): אילו קלפיות קפצו חריגות, באיזה מגזר,
כמה מצביעים נוספו ולאילו מפלגות הלכו הקולות.

**הדשבורד:** תיקיית [`docs/`](docs/) מתפרסמת ב־GitHub Pages.

קפיצה בשיעור ההצבעה מצביעה על מקום שכדאי לבדוק, ואינה ראיה לאי־סדרים.

## השיטה בקצרה

- **שיעור הצבעה** = מצביעים חלקי בעלי זכות בחירה (בזב), לכל קלפי ביתית. מעטפות כפולות אינן משויכות לקלפי ולכן אינן נכללות.
- **התאמה בין מערכות:** אותה קלפי כשהבזב יציב (±25–33%), אחרת אותו מקום קלפי (ריכוז, עד פי 2), אחרת היישוב כולו. העמודה "רמת ביטחון" מציינת מה שימש.
- **רצועות:** צהוב 10–15 נקודות אחוז, כתום 15–30, אדום 30 ומעלה, ובתנאי שהעלייה מובהקת: יותר מ־3 סטיות תקן מעל ההיסטוריה של הקלפי ולפחות 100 בזב.
- **מגזר:** לפי סוג היישוב בלמ"ס (יהודי, ערבי, בדואי, דרוזי, עיר מעורבת). בערים מעורבות וביישובים יהודיים, קלפי עם רוב למפלגות ערביות מסווגת "ערבי", וקלפי עם 60% ומעלה למפלגות חרדיות מסווגת "חרדי".
- **קולות שנוספו:** מצביעים בפועל, פחות הממוצע ההיסטורי כפול הבזב של 2026. החלוקה למפלגות לפי התפלגות ההצבעה באותה קלפי (שיטה א'), ולגושים גם לפי חלק הגוש ב־2022 (שיטה ב').

## בדיקות חוסן

- **מול קלפיות דומות:** לכל קלפי חושב העודף מעל השונות החציונית של קלפיות מאותו מגזר באותו יישוב (10 קלפיות לפחות), אחרת מאותו מגזר בכל הארץ, ביחידות פיזור עמיד (MAD). חריגה = עודף של 10 נק' לפחות ו־z של 3.25 לפחות.
- **Backtesting:** אותו כלל, אותה התאמה ואותם ספים הופעלו על בחירות 2021 ו־2022 כאילו הן הנוכחיות. הסף מול קלפיות דומות כויל כך שבבחירות האלה יסומנו לכל היותר כ־1% מהקלפיות.
- **התוצאה:** הכלל מול ההיסטוריה בלבד סימן 0.06% (2021) ו־0.36% (2022), לעומת 7.5% ב־2026. אבל רוב הסימונים ב־2026 הם עלייה של מגזר שלם (שונות חציונית של כ־33 נק' בקרב הבדואים בנגב, כ־23 נק' בקרב הערבים), ולכן כמעט אף קלפי ערבית או בדואית אינה חריגה ביחס לקלפיות דומות. כתום/אדום שחריגות גם מול קלפיות דומות, עם השוואה היסטורית אמינה: 28 קלפיות (0.23%) לעומת 8 ב־2022, עם כ־3,700 מצביעים נוספים, בעיקר ביישובים יהודיים ומתפזרים בין מפלגות רבות.

## הקבצים

| קובץ | מה יש בו |
|---|---|
| `ניתוח_שיעור_הצבעה_כנסת26.xlsx` | כל 12,018 הקלפיות, הקלפיות המסומנות, סיכומים לפי מפלגה, גוש ומגזר, בדיקות תקינות וקלפיות לבדיקה ידנית |
| `analyze.py` | הניתוח המלא: טעינה, התאמה, רצועות, מגזר, קולות שנוספו, Excel וקובצי הדשבורד |
| `validate.py` | בדיקות תקינות (כיסוי, חשבון, השוואה לקובץ היישובים, חישוב עצמאי) |
| `robustness.py` | השוואה לקלפיות דומות ו־Backtesting על 2021 ו־2022 |
| `build_site.py` | בונה את הדשבורד הציבורי ב־`docs/` |
| `dashboard/index.html` | קוד הדשבורד |
| `data/raw/` | קובצי המקור: תוצאות לפי קלפי (`expb`) ולפי יישוב (`expc`) לכנסות 21–26, וקובץ היישובים של הלמ"ס |
| `data/dash/` | הנתונים שהדשבורד מציג |

## הרצה מחדש

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python analyze.py
.venv/Scripts/python robustness.py
.venv/Scripts/python validate.py
.venv/Scripts/python build_site.py
```

`analyze.py` משתמש גם בקו המתאר של ישראל מ־[Natural Earth](https://www.naturalearthdata.com/) (`data/raw/ne_10m_countries.geojson`, לא נשמר במאגר בגלל גודלו):
<https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_10m_admin_0_countries.geojson>

## מקורות

- ועדת הבחירות המרכזית: `https://mediaNN.bechirot.gov.il/files/expb.csv` ו־`expc.csv` (NN = 21–26).
- הלמ"ס: קובץ היישובים `bycode2024.xlsx`.
- Natural Earth: גבולות מדינה, 1:10M.
